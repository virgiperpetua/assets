# Virginia Perpetua — brand rules

Flat, gridded, editorial. Archivo for heading (800) and body (400). Accent is light purple `#9b6ff3`, spent only on hierarchy and conviction — never as background decoration.

- Radius is `0` everywhere. Surfaces separate by 2px rules and fill, not shadow.
- Wordmark is uppercase **VIRGINIA PERPETUA** (Archivo 800). Mark is **VP** with an accent rule.
- Portrait photography stays grayscale in product UI unless a page explicitly overrides.
- Token values live in `@virginia-perpetua/tokens`. This repo holds binaries only.

Governing creative direction: `docs/design-export/brand-system-spec.md` (from Claude Design export).
